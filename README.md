# 칼로리 비서 (Calorie Assistant)

개인용 자동 칼로리 기록 및 관리 웹앱입니다. 별도의 서버나 설치 없이 HTML 파일 하나로 실행되는 단일 페이지 애플리케이션(SPA)입니다.

## 주요 기능

### 1. 대시보드
- 오늘의 총 섭취 칼로리 / 일일 한도 / 남은 칼로리를 진행 바로 표시
- 탄수화물·단백질·지방 섭취량을 목표치 대비로 표시 (목표 초과 시 빨간색 강조)
- 탄단지 비율 도넛 차트
- 아침/점심/저녁/간식 끼니별 섭취 현황 타임라인
- 부족한 영양소, 남은 끼니, 추천 음식을 포함한 구체적인 영양 조언 제공

### 2. 기록 (채팅형 UI)
- "+ 먹은 거 기록" 버튼으로 대화하듯 음식 → 수량 → 끼니 → 시간 순서로 입력
- **음식 다중 선택**: 한 끼에 여러 음식(예: 김치찌개 + 밥)을 함께 선택하면 자동으로 칼로리·영양소가 합산되어 기록됨
- **사진 자동 인식**: OpenAI Vision API(gpt-4o-mini)를 이용해 사진 속 음식을 자동으로 인식하고, 내장 음식 데이터베이스와 매칭하여 후보로 제시
- 기록된 항목은 언제든 칼로리/끼니/시간/사진 수정 및 삭제 가능
- CSV 내려받기로 하루 식단 데이터를 엑셀 등에서 활용 가능

### 3. 자동 일일 칼로리 한도 계산
- 설정에서 체중, 키, 나이, 성별, 활동량을 입력하면 Mifflin-St Jeor 공식으로 기초대사량(BMR)을 계산
- 활동량 계수를 반영한 유지 칼로리(TDEE)를 자동으로 일일 한도에 채워줌 (직접 수정도 가능)

### 4. 반응형 디자인
- 모바일: 전체 화면을 채우는 앱 형태
- 태블릿/PC: 중앙 정렬된 카드형 레이아웃으로 자동 전환되어 모든 화면 크기에서 사용 가능

## 사용 방법

1. `index_2.html` 파일을 웹 브라우저(Chrome, Safari, Edge 등)로 엽니다. 서버 설치나 인터넷 배포 없이 로컬에서 바로 실행됩니다.
2. 설정(⚙️)에서 체중, 키, 나이, 성별, 활동량을 입력하고 "체중·키 기반 일일 한도 자동 계산"을 눌러 목표 칼로리를 설정합니다.
3. (선택) 사진으로 음식을 자동 인식하려면 기록 화면 하단의 "API 키 설정"에서 OpenAI API 키를 입력합니다.
4. 기록 화면에서 "+ 먹은 거 기록" 또는 "📷 사진 올리기"로 식사를 기록합니다.
5. 대시보드에서 하루 섭취 현황과 영양 조언을 확인합니다.

## 사진 자동 인식(AI) 사용 시 참고사항

- 사진 인식 기능을 사용하려면 OpenAI 계정에서 발급받은 API 키가 필요합니다.
- 입력한 API 키는 본인의 브라우저(localStorage)에만 저장되며, 외부 서버로 전송되지 않습니다. 단, 사진 분석 요청 시 OpenAI 서버로 이미지와 키가 전송됩니다.
- 공용 PC에서 사용한 경우, 설정에서 키를 빈 값으로 재설정하여 삭제하는 것을 권장합니다.
- 비전 API 호출 비용은 사진 1장당 1원 미만 수준입니다(gpt-4o-mini 기준, 사용량에 따라 변동될 수 있음).
- API 키가 없거나 인식에 실패하면 음식 검색으로 직접 입력할 수 있도록 자동 전환됩니다.

## 데이터 저장

- 모든 기록(끼니, 설정, API 키)은 브라우저의 localStorage에 저장됩니다.
- 즉, 별도의 회원가입이나 서버 없이 완전히 로컬에서 동작하며, 다른 기기나 브라우저와는 자동으로 동기화되지 않습니다.
- 데이터를 백업하려면 기록 화면의 "CSV 내려받기"를 이용하세요.
- 브라우저 캐시/사이트 데이터를 삭제하면 기록도 함께 삭제되니 주의하세요.

## 기술 스택

- HTML / CSS / Vanilla JavaScript (프레임워크 없음)
- Tailwind CSS (CDN)
- Chart.js (탄단지 비율 도넛 차트)
- OpenAI API (gpt-4o-mini, 사진 속 음식 인식용, 선택 사항)
